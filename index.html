Shortcut Link

Steps for iOS:

There is also a do-it-along video at the end.

  1. “Shortcut Link” button above.
  2. “+ Add Shortcut.”
  3. “Automation.”
  4. “New Automation” button or the “+” button (top right).
  5. “Time of Day.”
  6. Set the time to whenever you’re likely to be connected to the internet (for example, 12:00 pm).
  7. Under “Repeat” select “Daily.”
  8. “Run Immediately” (keep the “Notify When Run” turned off).
  9. “Next.”
  10. “Shortcut Name” under “My Shortcuts” and you’re done!
  11. “Allow” whenever a message pops up requesting to fetch from the site.
